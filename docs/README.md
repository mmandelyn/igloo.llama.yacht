# Dev-Mary

The Favorite Name Catalog houses all of the favorite names from the users. 

## Project Requirements
1. Submit with a presentable README
2. the APP must clearly demonstrate the create, read, update, & delete (CRUD) functionality as HTTP “verbs” of POST, GET, PUT, DELETE.
3. code/environment
4. dev processes, issue/branch

## App Characteristics
1. Allows for users to enter their name or their favorite!
2. Once they click submit, their name will show on the list.
3. They can edit and update any existing names, and even delete it if they don't like it...
